# Visited Greek Islands Map — Render deployment

This package contains the Flask application and the data files it needs.

## Included files

- `app.py` — Flask routes and session-based island progress
- `coordinates.py` + `coordinates_cache.json` — pre-generated coordinates (no geocoding at startup)
- `read_the_list.py` + `islands.csv` — island census data and regional grouping
- `templates/index.html` — Leaflet map interface
- `requirements.txt` — Python dependencies
- `render.yaml` — Render Blueprint configuration

## Behaviour

- Every request to the homepage (`/`) clears the Flask session and starts with a clean map.
- Island selections are stored in that visitor's signed Flask session cookie; they are not a shared public tally.
- A stable `SECRET_KEY` is generated by Render through `render.yaml`.
- The support link defaults to `https://thx.so/chrisbaf/support`; change `SUPPORT_URL` in Render if needed.

## Deploy to Render

1. Create a GitHub repository, for example `greek-islands-map`.
2. Upload/push the **contents** of this folder to the repository root (so `app.py`, `render.yaml`, etc. are at the top level).
3. Sign in to Render and choose **New + → Blueprint**.
4. Connect the GitHub repository and deploy the Blueprint.
5. Render reads `render.yaml`, installs `requirements.txt`, generates `SECRET_KEY`, and starts `gunicorn app:app`.
6. Open the `onrender.com` URL shown by Render and test the map on desktop and mobile.

The free web service may spin down after inactivity. The first visit after it sleeps can take a little time to load. Check Render's current free-plan limits before launch; plan terms and allowances can change.

## Enable Cloudflare Web Analytics

Analytics is not active merely by deploying this package. You must create a Cloudflare Web Analytics site and add the site-specific beacon script Cloudflare gives you.

1. Open https://www.cloudflare.com/web-analytics/ and sign in/create a Cloudflare account.
2. In Web Analytics, add a site and enter the Render URL (later, update/add your custom domain if you use one).
3. Cloudflare will provide a JavaScript beacon snippet for that site.
4. Copy the complete snippet into `templates/index.html`, inside the `<head>` section, at the marked `CLOUDFLARE WEB ANALYTICS` comment. Replace the comment or paste the script immediately after it.
5. Commit/push the change to GitHub. Render will redeploy automatically if auto-deploy is enabled.
6. Return to Cloudflare Web Analytics to view page views, visitors and referrers. It can take a little while for data to appear.

Do not copy a generic snippet from another website: use the site-specific one Cloudflare generates for your domain.

## Local test (optional)

From this folder:

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Then visit http://127.0.0.1:5000.

## Before sharing publicly

- Check the displayed total and regional totals against your intended island dataset.
- Test clicking/un-clicking islands, reset, random destination, share and download.
- Open the homepage again to confirm it starts with a clean map.
- Review OpenStreetMap tile usage policy and attribution. This app uses the standard OSM tile endpoint; hosting the Flask app does not include a separate tile-service guarantee.
